# Study & Quran Timer

مؤقّت للدراسة مع تلاوة القرآن — تطبيق ويب بملف واحد يدعم العمل دون اتصال.
A study timer with Quran recitation, built as a single-page web app with offline support.

## Files
- `index.html` — the whole app
- `sw.js` — service worker (offline audio and caching)

## Run locally
Open `index.html` directly, or serve the folder (e.g. VS Code Live Server) so the service worker works.

## Live version
Served with GitHub Pages (https is required for offline mode).
